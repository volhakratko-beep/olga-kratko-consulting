# Consulting Site Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v1 homepage (`index.html` + `styles.css` + `script.js`) for the Olga Kratko consulting site, as one static, framework-free page.

**Architecture:** A single `index.html` with all 13 sections in document order, one shared `styles.css` (CSS custom properties for the design system, mobile-first responsive rules), and one small `script.js` for the mobile nav toggle and smooth-scroll to in-page anchors. No build step, no framework, no backend — opens directly in a browser or via a static file server.

**Tech Stack:** HTML5, CSS3 (custom properties, flexbox/grid), vanilla JS. Google Fonts (Inter) via `<link>`.

**Spec:** `D:\CODE\consulting-site\docs\superpowers\specs\2026-08-30-homepage-design.md`

## Global Constraints

- No invented content: names, numbers, credentials, and case results come verbatim (in meaning) from `D:\CODE\ai-learning\Site_project.odt`. Where the brief has no real value (email, LinkedIn, Telegram), use the literal placeholder text `[CONTENT NEEDED]`.
- Design tokens (brief §32-33): font Inter (fallback Manrope, DM Sans, system sans-serif); background `#FAF9F6` (warm off-white); text `#14181F` (dark navy/near-black); accent `#1E4FD8` (deep blue); optional secondary accent `#8A7CC4` (soft violet) — used sparingly, restrained palette.
- Mobile-first, responsive at four breakpoints: mobile (<640px), tablet (640-1023px), desktop (1024-1439px), large desktop (≥1440px).
- Semantic HTML, exactly one `<h1>` per page, logical heading order, visible focus states, alt text on all images, keyboard-operable nav — WCAG 2.2 AA where practical for v1 (brief §43).
- Every task ends with a real-browser check via the already-configured `chrome-devtools-mcp` MCP server (screenshot + console check), not a unit test — this project has no test framework, it's static markup.
- Portrait image path: `assets/olga-portrait.jpg` — file does not exist yet (user needs to supply it). Use `assets/portrait-placeholder.svg` (built in Task 2) until the real file is dropped in; do not block other tasks on it.

- [ ] **Step 4: Wire the mobile nav toggle in `script.js`**

```js
document.addEventListener('DOMContentLoaded', () => {
  const toggle = document.querySelector('.nav-toggle');
  const nav = document.getElementById('primary-nav');
  toggle.addEventListener('click', () => {
    const isOpen = nav.classList.toggle('is-open');
    toggle.setAttribute('aria-expanded', String(isOpen));
  });
  nav.querySelectorAll('a').forEach(link => {
    link.addEventListener('click', () => {
      nav.classList.remove('is-open');
      toggle.setAttribute('aria-expanded', 'false');
    });
  });
});
```
